# Space Runner

An exhilarating endless runner set in space! Control your avatar as they sprint from a moon station through the cosmos, dodging obstacles with smooth CSS sprite animations. Navigate through an ever-changing landscape with parallax scrolling backgrounds. How far can you run before the obstacles catch up to you?

## Quick Start

To run the game locally, use Python's built-in HTTP server:

```bash
python3 -m http.server 8000
```

Then open your browser and navigate to:

```
http://localhost:8000
```

## How to Play

1. **Start Running**: Your avatar automatically runs forward from the moon station
2. **Navigate Obstacles**: Use keyboard controls to move left and right, avoiding obstacles
3. **Stay Alive**: Don't hit any obstacles - one collision ends your run
4. **Go the Distance**: Try to run as far as possible through the endless space landscape
5. **Enjoy the View**: Take in the beautiful parallax scrolling backgrounds as you run

**Strategy**: Stay focused and react quickly! The further you run, the more challenging the obstacles become. Master the controls to achieve your longest distance record in this cosmic adventure!
