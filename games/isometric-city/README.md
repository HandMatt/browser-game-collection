# Isometric City

Build and manage your own 2.5D city! Place buildings to generate coins, diamonds, and power while growing your population. Balance resources to expand your metropolis and collect wealth. A strategic city-building game with beautiful isometric graphics.

## Quick Start

To run the game locally, use Python's built-in HTTP server:

```bash
python3 -m http.server 8000
```

Then open your browser and navigate to:

```
http://localhost:8000
```
